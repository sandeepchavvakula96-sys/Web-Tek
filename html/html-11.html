Internal and External CSS Styling

Understanding the structure of Internal and External CSS

CSS Styling Structure

CSS can be added to an HTML webpage in different ways. This experiment demonstrates both Internal CSS and External CSS.

1. Internal CSS

Internal CSS is written inside the <style> tag in the <head> section. 

<head>

    <style>

        h1 {
            color: blue;
            text-align: center;
        }

        p {
            color: green;
        }

    </style>

</head>

2. External CSS

External CSS is written in a separate .css file and connected using the <link> tag. 

<head>

    <link
        rel="stylesheet"
        href="style.css"
    >

</head>

External CSS File Structure 

/* style.css */

body {
    background-color: lightblue;
}

h1 {
    color: purple;
    text-align: center;
}

p {
    color: darkgreen;
}
