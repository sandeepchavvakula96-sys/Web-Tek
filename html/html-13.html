Responsive Webpage with Media Queries

This page demonstrates Responsive Webpage with Media Queries using proper HTML and CSS structure.

Desktop

On large screens, the cards appear in three columns.

Tablet

On tablets, the layout changes to two columns.

Mobile

On mobile screens, the cards appear in one column.

Responsive Design

Resize your browser window to see the layout automatically change.

Media Query Example 

@media (max-width: 768px) {

    .container {
        width: 95%;
    }

    .cards {
        grid-template-columns: 1fr 1fr;
    }
}

@media (max-width: 600px) {

    .cards {
        grid-template-columns: 1fr;
    }
}
